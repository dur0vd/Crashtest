# Правила для агентов (Codex, Claude и др.)

Проект — симулятор дорожных ситуаций с разбором по ПДД / КоАП / УК РФ. Описание — в `README.md`, план работ — в `docs/PLAN.md`.

## Перед каждым коммитом

```bash
npm ci
npm test          # vitest, должен быть зелёным
npm run build     # tsc --noEmit + vite build
```

## Соглашения

- TypeScript без фреймворков. Интерфейс, комментарии, сообщения коммитов — **на русском**.
- `sim.ts`, `analysis.ts`, `restrictions.ts`, `geo.ts`, `geom.ts` — чистые функции от сцены, без DOM. Не тянуть туда `document`/`window`.
- `src/data/*.json` не править руками: они собираются скриптами `tools/*.py`.
- Новое поле в `Scene`/`Actor` — обязательно значение по умолчанию в `normalizeScene` (старые сохранения и ссылки должны открываться).
- Новое правило в разборе — ссылка на пункт ПДД / статью КоАП или УК из `law.ts`/корпуса, плюс тест.
- Новая возможность моделирования — желательно пример в `presets.ts`; все примеры прогоняются в `tests/analysis.test.ts`.
- Если пункт из «Ограничений текущей версии» в `README.md` закрыт — убрать его оттуда и описать возможность в «Что умеет».
- Одна задача из `docs/PLAN.md` — одна ветка и один PR. Отмечайте выполненное в плане.
