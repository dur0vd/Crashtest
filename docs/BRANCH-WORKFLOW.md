# Три независимые ветки и одно объединение

Актуальная схема — [четыре промпта](prompts-four/README.md).
Общая неизменяемая база `codex/full-simulator-base-v2` содержит уже проверенные
парковку/СИМ/пассажиров и общий контракт. `base-v1` остаётся историческим снимком.

1. В трёх разных чатах одновременно запустить физику, графику и правила.
   У каждого своя ветка/worktree из TXT. Они не сливают и не ждут соседей;
   делают свою область через фиксированные интерфейсы общей базы.
2. Внутри каждого чата работать по проверяемым подэтапам, делать commit/push
   и вести единственный собственный handoff. Существующее готовое не повторять.
3. Когда три результата опубликованы, запустить четвёртый промпт.
   Он фиксирует входные SHA, merge-ит ветки в `codex/parallel-integration`,
   подключает реальные порты, проверяет целое и публикует итоговую ветку.
   main/ветки авторов не переписываются.

Независимость обеспечивают [контракт и владельцы файлов](PARALLEL-CONTRACT.md).
Проверка фактического состояния: [аудит](STATUS-AUDIT-2026-10-22.md).
Старая очередь из 23 задач заменена; её handoff — источник истории и ограничений,
а не приказ ждать ранее отсутствующие ветки.
