# Фактическое локальное поведение Crashtest

Графическая ветка, контракт 1. Это описание реализации, не юридическое заключение.

## Данные и хранение

В проекте могут быть номера ТС, полисы, контакты, адрес, пояснения, оригинальные
фото/видео/аудио, EXIF, геопозиция и история правок. `IndexedDB` базы
`crashtest-projects-v1`, store `projects`, ключ `current` хранит проект и вложения.
Камера/панорамирование не записываются как правки исходных данных. Старый
`localStorage` читается для миграции, затем удаляется после успешного сохранения
в IndexedDB. Хранилище браузера по умолчанию **не зашифровано**; доступ к профилю
браузера/устройству даёт доступ к проекту. Ошибка квоты/сохранения показывается.
Скачанные пользователем файлы находятся вне управления приложения.

Оригиналы сохраняются побайтово. SHA-256 проверяет соответствие байтов, не
удостоверяет автора, дату съёмки или достоверность содержания. EXIF может
отсутствовать, быть неподдерживаемым или недостоверным; приложение это не
исправляет и не выдаёт время импорта за время съёмки. Текущая геопозиция и
точность браузерного API хранятся отдельно от EXIF.

## Сеть

Нет загрузки материалов на сервер, аналитики, внешних CDN, OSM-запросов или
облачного распознавания. Браузер загружает JS/CSS/шрифт/значки/корпус с origin
приложения. CSP разрешает `connect-src 'self'`, локальные blob для медиа/worker
и data/blob для картинок. Нормативные ссылки открываются только действием
пользователя; они ведут на внешние сайты и не содержат содержимое проекта.
Геолокация — системный API по нажатию пользователя; механизм определения
места/сетевые действия ОС не контролируются веб-приложением.

Аудит реальных запросов production Chromium в
`docs/graphics-verification/network.json`: проверяются origin запросов при
редактировании, загрузке материалов, видео, PDF и перезагрузке. Это аудит
конкретного сценария, не доказательство поведения всей ОС/всех зависимостей.
Браузерный тест падает при внешнем запросе. Service Worker кэширует только
явный список статических файлов текущей сборки (включая шрифт и lazy chunks),
не файлы проектов или содержимое IndexedDB. После завершения установки кэша
отображается готовность офлайн; первый запуск требует загрузки приложения.
Нативный Capacitor содержит те же локальные веб-ресурсы.

## Экспорт, шифрование и обезличивание

В рабочей области URL-share отключён для всех проектов. Старые `#s=` ссылки
остаются читаемыми для совместимости; приложение их не создаёт заново.
Обычный ZIP, PDF, DOCX и старый Scene JSON могут содержать персональные данные.

Непустой пароль на вкладке проекта шифрует ZIP через WebCrypto:
PBKDF2-HMAC-SHA256, 310000 итераций, случайные salt 16 байт и nonce 12 байт,
AES-256-GCM с аутентифицированным заголовком. Пароль не сохраняется и не
передаётся. Неверный пароль и изменение ciphertext отвергаются. CLI принимает
имя переменной окружения, не пароль в аргументе. Встроенная защита не заменяет
надежный пароль и защиту устройства.

«Экспорт без ПДн» создаёт отдельную **производную схему** по белому списку:
геометрия/численные измерения, обезличенные ID, без свободного текста,
проектных extensions, оригиналов и производных фото, EXIF, адреса/даты/гео,
номеров/полисов, журнала/старых состояний, расчётов и правовой оценки.
Это намеренная потеря сведений, не оригинал доказательственных материалов.
Редактируемый оригинал не меняется. Координаты схемы сохраняются: сама
геометрия может позволять сопоставление с известным местом; автоматическая
юридическая гарантия анонимности не заявляется.

Обезличенный PDF строится заново из этой производной, без исходного Report,
ответов, автора и свободного текста оригинала. Ручное маскирование фото
выполняется локально: непрозрачная область создаёт PNG без EXIF; оригинал
остаётся в полном проекте. Пользователь проверяет полноту маски. Redacted ZIP
консервативно исключает все фото, включая такие производные.

## Удаление и мобильные разрешения

Кнопка удаления удаляет проект и все вложения из IndexedDB и старую запись
localStorage; рабочее состояние заменяется пустой сценой. Экспортированные
файлы/резервные копии ОС/копии другого пользователя удаляются отдельно.
Android `allowBackup=false`; мобильные разрешения камеры/микрофона/гео
объявлены для явных действий пользователя. Нативные сборки не подтверждены:
в среде нет Xcode/Android SDK; `cap sync` проверен отдельно.

Микрофон записывает локальное аудио через MediaRecorder только по нажатию.
Никакой скрытой отправки браузерному SpeechRecognition нет; основной fallback —
текст. При смене вкладки/закрытии микрофон останавливается.
