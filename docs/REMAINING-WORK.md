# Оставшаяся работа: четыре чата

По последнему указанию пользователя прежние 23 задания заменены четырьмя.
Три запускаются одновременно без ожидания соседних веток; четвёртый проверяет
и объединяет их. [Четыре отдельных промпта](prompts-four/README.md).

Проверено на GitHub и в общем коде: 04–05, 06.1–06.3 и новые реализации
парковки/СИМ/пассажиров. Общая регрессия: 1115 тестов в 35 файловх и build.
Все оговорки этих модулей сохранены. Ветки 07.2/08.1 пока подготовительные,
динамику сцены/удар они не реализуют; отдельное ядро 07.1 уже включено. [Доказательства и остаток](STATUS-AUDIT-2026-10-22.md).

| --- | --- |
