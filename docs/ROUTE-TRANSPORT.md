# Маршрутные транспортные средства

Подпункт 06.3 добавляет проверки раздела 18 ПДД по локальному корпусу.
Автобус в каталоге — тип транспортного средства, а выполнение регулярной
перевозки по установленному маршруту задаётся отдельным известным фактом.

## Полоса и остановочное место

Выделенная полоса связана с дорогой. Начало и конец измеряются вдоль её
оси; поперечное смещение положительно вправо от авторского направления
оси. Ширина, направление, связанные знаки, характер границы, правое
положение полосы и источник задаются явно. Это позволяет описать также
встречную выделенную полосу и одностороннюю дорогу, не меняя смысл
нумерации обычных полос.

5.14.1. Поддерживаются оба обозначения. `TODO(legal-check)`: сверить
номера и редакции по первоисточнику. Одна разметка 1.23.1 не подменяет
необходимые знаки. Граница действия полосы задаётся геометрией, а
связанный знак окончания также учитывается при проверке.

Остановочное место связано с дорогой и обозначающим его знаком либо
разметкой. В текущем корпусе 1.17.1 обозначает остановки маршрутных ТС
и стоянки такси, 1.17.2 — трамвайную остановку с посадкой с проезжей
части или площадки. Эти обозначения не являются безусловным запретом
остановки для всех участников. Общие запреты раздела 12 рассматриваются
в следующем подпункте.

## Условия допуска

Выполнение регулярного маршрута, школьный автобус, легковое такси и
полный установленный набор условий регионального допуска — отдельные
факты. Неизвестное значение не равно «нет». Фактическая масса из
кинематической модели не заменяет разрешённую максимальную массу
для регионального исключения. Велосипедное исключение 18.2 относится
к правой выделенной полосе; возрастные и остальные требования раздела
24 проверяются отдельно.

Для временного въезда через прерывистую границу нужны соответствующий
наблюдаемый манёвр и отсутствие помех маршрутным ТС. Флаг посадки
пассажиров сам по себе не разрешает последующий сквозной проезд по
полосе. Допуск к движению по полосе не отменяет запрет пересечения
сплошной границы. Правомерное движение допущенного ТС по встречной
выделенной полосе отдельно учитывается при обычной проверке стороны
движения.

Маршрутные исключения знаков проверяются по их примечаниям. Для
3.27 важны также соответствующие обозначенное место и статус ТС;
обычный автобус не получает все исключения только по каталожному типу.
Примечание группы 4 исключает маршрутные ТС из 4.1.1–4.1.6 в целом,
даже без выделенной полосы. Исключения из указанных в 18.2 знаков не
переносятся автоматически на стрелочную разметку 1.18.

## Выезд от остановки и трамвай

Для 18.3 нужны автобус либо троллейбус, обозначенное остановочное
место, населённый пункт и наблюдаемая последовательность «остановка —
начало движения». Условие регулярного маршрута в самом 18.3 не указано.
Проезжающий мимо знака автобус не считается начинающим движение от
остановки. Водитель начинает движение, лишь убедившись в уступании;
этот факт задаётся для конкретной пары участников. Неуступание другого
водителя и небезопасное начало движения автобуса могут быть установлены
одновременно.

Преимущество трамвая при пересечении путей с проезжей частью вне
перекрёстка проверяется по 18.1, включая исключение выезда из депо.
Железнодорожный поезд не становится трамваем для этой проверки.

## Квалификация и пределы

Установленное неуступание по 18.3 связывается с 12.17 частью 1.
Неправомерное попутное использование выделенной полосы — с частью 1.1,
а в Москве и Санкт-Петербурге — с частью 1.2. Севастополь не включён
в повышенную часть. При неизвестном месте часть автоматически не
выбирается. Случаи встречного выезда по 12.15 частям 3–5 не дублируются
обычной квалификацией попутной выделенной полосы.

вынужденной остановки, остановки по трафику и добровольной стоянки
дополняется в 06.4.
