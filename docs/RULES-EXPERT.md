# Научное доказательство и норма

Публичный RulesPort по умолчанию использует `extensions.rules.mode = expert`.
Legacy `analyze(scene, timeline)` сохранён; явный `educational` сохраняет его
упрощённую научную часть и маркирует это в отчёте. Новых формул торможения,
травм и скрытых коэффициентов в правилах нет.

В expert геометрические события из готового технического анализа сохраняются,
а учебные остановочные пути и категории вреда не используются как доказательство.
`technical.collisions[].harm/tech` пусты при неизвестности с обязательными
`trace.harmStatus = unknown` и `avoidanceStatus`; это НЕ нулевой вред/путь.
Обязанности после ДТП выводятся условно по наличию пострадавших; отсутствие
медицинских данных не включает автоматически сценарий «только имущество».
Технически зависимые 10.1 и причины превышения скорости без расчётного
доказательства не получают определённого вывода. Геометрически установленные
самостоятельные нормы сохраняются.

## Адаптер версии 1

`extensions.rules.expert.bindings` — массив
`{actorId, recordId, observationId}`. Наблюдение находится в `project.evidence`
или `PhysicsOutput.observations`. Повтор одного и того же объекта через порт
допустим, конфликтующие ID отвергаются. Сам PhysicsOutput должен соответствовать
переданному Timeline: шаг/длительность/коэффициент, все массивы треков,
waypointTimes и столкновения. Сторонние результаты не мутируются.

Поддерживаемый CalculationRecord:

```json
{
  "id": "service-braking-a",
  "method": "expert.braking",
  "inputs": {
    "actorId": "a", "observationId": "yellow-a", "brakingMode": "service",
    "t1": 0.7, "t2": 0.2, "t3": 0.3
  },
  "formula": "Фактическая формула и подстановка, переданные портом физики",
  "result": { "stoppingDistanceRangeM": [20, 24] },
  "units": { "t1": "s", "t2": "s", "t3": "s", "stoppingDistanceRangeM": "m" },
  "sources": ["Фактический источник метода/параметров"],
  "assumptions": ["Явные условия применимости физического расчёта"]
}
```

Это только пример структуры, НЕ рассчитанный физический пример. Продукт не
возвращает его как расчёт. Источники/числа задаёт настоящий научный порт.
Адаптер проверяет пригодность структуры, не сертифицирует метод/источник.

Наблюдение для жёлтого:

- `kind = yellow-stop-line`, `source` непустой;
- `values: {actorId, lightId, frame, yellowOnsetEstablished: true, availableDistanceRangeM: [min,max]}`;
- `uncertainty: {availableDistanceUnit: "m"}`;
- `frame` соответствует установленному началу жёлтого в наблюдаемом событии,
  `lightId` — его светофору.

Правило сравнивает только интервалы: `max(S) ≤ min(available)` — технически
возможно, `min(S) > max(available)` — невозможно, пересечение — неизвестно.
Это логическое сравнение переданных доказательств, не тормозная формула.
Невозможность служебной остановки даёт исключение 6.14; возможность — его
неприменимость; отсутствие t3/единиц/источников, устаревший Timeline,
неустановленное начало жёлтого и пересечение диапазонов дают неопределённость.
Наличие ссылки 6.14 само по себе больше не превращает неизвестность в соблюдение.

Наблюдение `kind = collision-avoidance` может содержать отдельно установленные
`hazardOnsetEstablished`, `hazardPerceivable`, `driverFailedToBrake`.
Возможность остановиться сама по себе не устанавливает нарушение 10.1:
нужны эти факты. Причинность требует отдельного
`causalLinkEstablished` с источником наблюдения; контакт не заменяет его.
Ускорения/замедления/медицинские коэффициенты правилом не вычисляются.

Для интегратора: экспорт `readExpertEvidence`, `prepareExpertContext`,
`applyExpertResults`, общая фабрика `createRulesPort`. `contracts.ts` не менялся.
В TechnicalSection добавлены необязательные `calculations` и `scientific`.
Если физика использует иной result-формат, нужен точный адаптер к описанной схеме;
не подставлять учебные значения. Отсутствие такого результата не мешает остальным
нормам; неопределённость выводится только для зависимого заключения.

Источник нормы — [6.14 ПДД](https://www.consultant.ru/document/cons_doc_LAW_2709/4b7a10a56ed37080fc96999db5f3db6f3aa58cc6/),
точный текст и редакция раскрываются `lawRef('pdd:6.14', accidentDate)` из корпуса.
Проверки используют заданные вручную треки/доказательства и независимую таблицу
интервалов. Это верификация правил, не натурная валидация физики.
