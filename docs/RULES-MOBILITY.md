# Проверенные дополнения раздела 24

`extensions.rules.mobility.actors[id]` содержит только новые факты о руле,
допустимости пассажирского места, буксировке, группах колонны, отражателях и
наблюдаемом пересечении вне перекрёстка. Полный набор — `describe(project)`.
Возраст, пассажиры, мотошлем, колонна/один ряд, условия инфраструктуры и
установленные последствия остаются в существующих полях Actor. Научные
коэффициенты защиты и масса пассажиров не вычисляются и не добавляются.

Доработаны 24.5, 24.8–24.10, 24.6(1), распознаваемые левые повороты вне
перекрёстка, подтверждённая велосипедная зона 24.11. Порог 0,5 м, ширина 0,75 м,
группы до 10 велосипедистов/10 пар и промежуток 80–100 м берутся из нормы.
Пороги распознавания трека остаются ограничениями наблюдения, не правовыми
порогами. Наличие отражателей в городе рекомендуется, нарушение обязанности
24.10 выводится только для установленной темноты/недостаточной видимости
вне населённого пункта. Квалификация не выводится из контакта.
