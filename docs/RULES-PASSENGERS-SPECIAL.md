# Специальные пассажирские условия

Вход: `extensions.rules.passengers.actors[actorId]`; дополнительные факты о
конкретном пассажире — `people[passengerId]`, с ID из существующего
`Actor.passengers`. Возраст, место, ремень/ДУУ/шлем, вместимость и общие условия
посадки повторно не заводятся. Новые поля доступны через `describe(project)`.

Выполнены проверки 22.1–22.5: C/C1 и три года, дополнительные D/D1 при количестве
более 8/16 человек, отдельное установленное военное исключение; бортовая
платформа/кузов-фургон, оборудование, дети, сидячие места, инструктаж;
сопровождающий груз/следующий за ним и сиденье ниже бортов для 22.5.
Вместимость бортового кузова сравнивается с пассажирами в кузове; категории
22.1 — со всеми пассажирами, включая кабину, без водителя.
Список пассажиров считается полным только в пределах авторского ввода.

Проверки 5.1/5.2 сохраняют личный субъект пассажира. Пассажирская квалификация
12.29(1) с установленным возрастом от 16 выводится отдельным элементом
`legal.duties` с `trace.subject.kind = passenger`, а не составом водителя.
Наблюдение хранится в `rules.findings` с `trace.legalSubject = passenger` и ID;
оно не меняет водительский verdict. Ремни и детские обязанности водителя из
базы сохранены. Для одной квалифицируемой обязанности специальная часть
12.23 исключает общую часть 1; разные действия не склеиваются в один состав.

Организованные группы не устанавливаются из количества пассажиров: используется
имеющийся `passengerContext.organizedChildren`. Проверяются автобус/знаки 22.6.
С 01.09.2026 доступен подтверждённый набор Правил №680, с окончанием 01.09.2032:
субъект п.3, возраст/4 часа п.8, ночное время 23–6 и 100 км п.12, ремни/маячок
пп.17–18, водитель п.19, документы водителя п.20. Пункт 8 относится к
организатору: личность и статус ответственного не подменяются водителем,
часть 6 ст.12.23 ему не назначается. Ночные условия используют местную дату и
время ДТП; отсутствие времени остаётся неизвестностью. Это проверка заданных
обстоятельств, не автоматическое подтверждение организованной перевозки.

- [ПДД, обязанности пассажиров](https://www.consultant.ru/document/cons_doc_LAW_2709/ebac29ce89bbf83c3390095a126a259f746a0cb8/).

Не выбирать штраф физлица для ИП/самозанятого такси без проверки примечаний и установленного статуса.

Пункт 3 постановления подтверждает даты действия, пункт 2 отменяет №1527/2165. Официальный URL в этой среде недоступен; нормативный текст проверен в опубликованной копии, зеркало и первичный адрес указаны раздельно.
- [Постановление 525-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_523068/): изменения 12.23(3) и примечания о самозанятом водителе такси.
