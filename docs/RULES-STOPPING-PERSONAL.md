# Личные обязанности при остановке

Новая проверка уточняет результаты готового `analysis/stopping.ts`; повторной
геометрии парковки нет. `extensions.rules.stopping.actors[id]` хранит только
`doorPassengerId` (ID в существующем списке) и `triangleAttachedRear` для 7.3.
Остальные факты берутся из stopContext/doorContext/warningContext.

Разделены дверь, меры при уходе и ребёнок при стоянке. Водительское нарушение
12.8 сопоставляется с общей 12.19(1), для Москвы/Санкт-Петербурга — (5),
только при известном городе. Дверь водителя: отдельная 12.19(4)/(6) выбирается
при установленном нахождении на проезжей части и помехе другому ТС; неизвестное
положение, оператор или вид помехи не подменяются общей частью. Действие
пассажира — отдельный субъект в legal.duties, возраст от 16 для 12.29(1),
без назначения этой ответственности водителю. Причинность не выводится из
двери, ухода, ребёнка, контакта или геометрического запрета стоянки.

Меры 12.6 остаются отдельным наблюдением: установленная возможность и отсутствие
мер дают нарушение требования, но точный состав за это без проверенного
разграничения вынужденной остановки и специальных исключений не назначается.
Пункт 7.3 проверяет закрепление знака сзади буксируемого ТС при неисправности/
отсутствии аварийной сигнализации; знак на дороге 7.2 его не подменяет.
Активность hazard по-прежнему только vehicleSignalAt.
