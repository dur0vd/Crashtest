# 02. Нормы в редакции на дату ДТП, сверка санкций

Ветка: `codex/02-law-versions` ← от `main`

## Промпт

```
Работай в отдельной ветке codex/02-law-versions. Создай её от main.
Не коммить в main и в чужие ветки. В конце: npm test и npm run build зелёные, коммит, git push -u origin codex/02-law-versions.

Прочитай AGENTS.md. В Crashtest разбор сейчас опирается на одну редакцию норм (src/law.ts,
src/data/pdd.json, koap.json, uk.json; константа LAW_CHECKED). Для экспертной и судебной работы нужно
применять ПДД, КоАП и УК в редакции на дату ДТП.

Сделай:
1. Модель данных редакций. Каждая норма (пункт ПДД, часть статьи КоАП/УК) хранит список редакций
   { validFrom: 'YYYY-MM-DD', validTo?: string, text, sanction?, source: { url, docTitle, revisionDate } }.
   Миграция существующих JSON: текущий текст становится редакцией с validFrom = дата из источника.
2. В сцене поле env.accidentDate (дата и время ДТП). В UI — во вкладке «Среда». По умолчанию — сегодня.
3. lawRef(id, date) возвращает редакцию на дату; все места разбора (analysis.ts, restrictions.ts, ui.ts)
   передают дату сцены. Если на дату нет данных — явное предупреждение в отчёте, а не молчаливая подстановка.
4. tools/fetch-law.py и tools/build-law.py: научить собирать редакции (consultant.ru хранит редакции
   документа; ПДД — по постановлениям Правительства о внесении изменений). Сохраняй URL и дату каждой
   редакции. Скрипты запускаются вручную; в CI сеть не нужна — результат коммитится в src/data/.
5. Сверка санкций. Пройди все записи с sanction в src/law.ts (12.7, 12.8, 12.9, 12.12, 12.13, 12.14,
   12.15, 12.16, 12.18, 12.21, 12.21.1, 12.24, 12.27, 12.29, ст. 264) и сверь с текстом из корпуса.
   Сейчас часть сумм выглядит индексированной, а часть — старой (12.13 ч. 2, 12.18, 12.27 ч. 1), у ч. 1
   ст. 12.7 санкции нет вовсе. Санкцию бери не из пересказа, а из текста части статьи в корпусе — сделай
   её производной от корпуса, чтобы два источника не расходились.
6. Тест tests/law.test.ts: для каждой ссылки, используемой разбором, на дату по умолчанию есть редакция;
   санкция в кратком справочнике совпадает с корпусом; нет пересекающихся интервалов редакций.
7. В отчёте разбора (и в будущем PDF) рядом с каждой нормой — «в редакции от …, источник …».

Не выдумывай даты редакций и суммы: если не удалось получить из источника — TODO(legal-check).
Проверка: npm test, npm run build.
```
