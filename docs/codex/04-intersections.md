# 04. Проезд перекрёстков полностью (раздел 13 ПДД)

## Промпт

```
Прочитай AGENTS.md. В Crashtest приоритет на перекрёстке (resolvePriority в src/analysis.ts, после задачи 03 —
src/analysis/traffic-rules.ts) учитывает только светофор, знаки 2.1/2.4/2.5, трамвай, левый поворот и помеху
справа. Доведи до полного раздела 13 ПДД. Тексты пунктов бери из src/data/pdd.json, не по памяти.

1. Перекрёсток как сущность в src/geo.ts: автоматически определять пересечение дорог, его границы
   (по п. 1.2 «Перекрёсток»), регулируемый/нерегулируемый, равнозначный/неравнозначный, въезды и выезды.
   Траектории участников классифицировать: прямо, направо, налево, разворот — по въезду и выезду.
2. Пункты: 13.1 (при повороте уступить пешеходам и велосипедистам на пересекаемой проезжей части),
   13.2 (выезд на перекрёсток при заторе, сетка 1.26), 13.3, 13.4, 13.5 (дополнительная секция —
   уступить), 13.6 (трамвай и безрельсовое при одновременном разрешающем), 13.7 (выезд с перекрёстка
   по любому сигналу), 13.8, 13.9, 13.10 (главная меняет направление, табличка 8.13), 13.11, 13.11(1)
   (кольцевой перекрёсток, знак 4.3), 13.12, 13.13 (нельзя определить покрытие — считать второстепенной).
3. Светофоры: дополнительные секции со стрелками (п. 6.3), стрелка на основном сигнале, мигающий
   жёлтый = нерегулируемый (п. 6.2, 13.3), реверсивные и трамвайные светофоры, регулировщик (п. 6.10–6.11)
   — хотя бы как статический объект с жестом.
4. Одновременный подъезд нескольких ТС: строить граф «кто кому уступает» для всех участников, а не попарно;
   при цикле (равнозначный, все с разных сторон) — вывод «водители договариваются, см. п. 13.11 и 1.5»,
   без назначения нарушителя.
5. Редактор: знак 4.3 и кольцо как шаблон дороги; табличка 8.13 с направлением главной.
6. Пресеты и тесты на каждый пункт: минимум по одному сценарию «правильно» и «нарушение».
   Ссылки — ч. 1/2 ст. 12.13 КоАП, ст. 12.18 (п. 13.1), ч. 1 ст. 12.13 (п. 13.2). Сверь части статей по корпусу.

Проверка: npm test, npm run build.
```
