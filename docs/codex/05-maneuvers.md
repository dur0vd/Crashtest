# 05. Манёвры, указатели поворота, обгон, задний ход

Ветка: `codex/05-maneuvers` ← от `codex/03-qualification`

## Промпт

```
Работай в отдельной ветке codex/05-maneuvers. Создай её от codex/03-qualification (если в origin её нет — остановись и сообщи, что сначала нужна та задача).
Не коммить в main и в чужие ветки. В конце: npm test и npm run build зелёные, коммит, git push -u origin codex/05-maneuvers.

Прочитай AGENTS.md. В Crashtest нет сигналов поворота, а манёвры оцениваются частично (п. 8.1, 8.3, 8.4, 8.8).
Нужно покрыть разделы 8 и 11 ПДД. Тексты пунктов — из src/data/pdd.json.

1. Модель: у точки траектории (Waypoint в src/scene.ts) поле signal: 'none' | 'left' | 'right' | 'hazard'
   и время включения. Автоподсказка в редакторе: при изменении направления предложить включить сигнал.
   Отрисовка мигания в src/render.ts. Миграция старых сцен: signal = 'none'.
2. Проверки:
   - 8.1–8.2: сигнал не подан или подан слишком поздно перед манёвром (заблаговременность — параметр,
     по умолчанию ориентир в секундах/метрах, вынеси в константу с комментарием, что ПДД числа не задают);
     сигнал не выключен после манёвра; сигнал не даёт преимущества;
   - 8.5–8.7: заблаговременно занять крайнее положение перед поворотом/разворотом; исключения для
     длинномерных ТС (8.7);
   - 8.6: поворот так, чтобы не оказаться на встречной стороне при выезде с пересечения;
   - 8.9: пересечение траекторий вне перекрёстка, когда очерёдность не оговорена — уступить ТС справа;
   - 8.11–8.12: запрет разворота в указанных местах; движение задним ходом (новый режим скорости < 0
     в траектории) — безопасность, запреты на перекрёстках, переходах, мостах и т. д.;
   - 11.1–11.7: обгон и опережение полностью — запрет обгона ТС, подающего сигнал левого поворота (11.2),
     не препятствовать обгону (11.3), места запрета (11.4) с переходами, мостами, тоннелями, переездами,
     опережение на переходе (11.5), встречный разъезд (11.7).
3. Причинная связь: если у одного участника нет сигнала, а другой исходил из того, что тот едет прямо,
   отразить в «Соответствии ПДД»; правовая ссылка — ч. 1 ст. 12.14 КоАП и т. д. (сверь по корпусу).
4. Пресеты: обгон поворачивающего налево (классика спора по ОСАГО), разворот с правой полосы, выезд задним
   ходом с парковки, перестроение без сигнала. Тесты на каждый.

Проверка: npm test, npm run build.
```
