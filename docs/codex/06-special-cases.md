# 06. Особые случаи: переезды, спецтранспорт, остановка, велосипедисты, световые приборы

Ветка: `codex/06-special-cases` ← от `codex/03-qualification`

## Промпт

```
Работай в отдельной ветке codex/06-special-cases. Создай её от codex/03-qualification (если в origin её нет — остановись и сообщи, что сначала нужна та задача).
Не коммить в main и в чужие ветки. В конце: npm test и npm run build зелёные, коммит, git push -u origin codex/06-special-cases.

Прочитай AGENTS.md. В README Crashtest перечислено, что не моделируется. Закрой это. Каждый пункт ниже —
отдельный коммит с тестом и пресетом. Тексты норм — из src/data/*.json.

1. Железнодорожный переезд (раздел 15 ПДД): объект «переезд» со шлагбаумом и светофором,
   поезд как участник по рельсам с большой массой и тормозным путём; запреты 15.3; ст. 12.10 КоАП.
2. Спецтранспорт (п. 3.1–3.4): флаг у ТС «проблесковый маячок синего цвета и звуковой сигнал»;
   обязанность уступить (3.2) и условия, при которых спецТС может отступать от правил (3.1 —
   только убедившись, что ему уступают); ст. 12.17 КоАП. Сопровождение колонн — по желанию.
3. Маршрутные ТС (раздел 18): полоса для маршрутных ТС (знак 5.14), выезд автобуса от остановки (18.3);
   ст. 12.17 КоАП.
4. Остановка и стоянка (раздел 12): места запрета (12.4, 12.5), знаки 3.27–3.30, разметка 1.4, 1.10,
   стоянка на тротуаре, второй ряд; открывание двери (12.7); вынужденная остановка и знак аварийной
   остановки (7.2) — расстояние 15/30 м; ст. 12.19, 12.20 КоАП. Столкновение с неправильно стоящим ТС —
   причинная связь оценивается отдельно.
5. Велосипедисты и СИМ (раздел 24): где можно ехать, возраст, пересечение по переходу (24.8),
   велополоса и велодорожка, ст. 12.29 ч. 2 КоАП. СИМ (самокаты) — как отдельная категория по
   актуальной редакции ПДД.
6. Световые приборы (раздел 19): ближний/дальний свет, ослепление, аварийная сигнализация; заготовка под
   время суток из задачи 10.
7. Пассажиры (раздел 22): перевозка детей, ремни — как флаги, влияющие на оценку вреда (задача 09) и
   правовую часть (ст. 12.6, 12.23 КоАП).
8. Обнови раздел «Ограничения текущей версии» в README.md.

Проверка: npm test, npm run build.
```
