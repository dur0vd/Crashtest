# 07. Динамическая модель транспортного средства

Ветка: `codex/07-vehicle-dynamics` ← от `main`

## Промпт

```
Работай в отдельной ветке codex/07-vehicle-dynamics. Создай её от main.
Не коммить в main и в чужие ветки. В конце: npm test и npm run build зелёные, коммит, git push -u origin codex/07-vehicle-dynamics.

Прочитай AGENTS.md. Сейчас src/sim.ts — кинематика: ТС едет точно по траектории с заданной скоростью,
ускорения не ограничены сцеплением, кузов не вращается после удара. Для реконструкции нужна динамика.

Сделай новый модуль src/physics/ (старый кинематический режим оставь как «упрощённый» для обучения,
выбор режима в env.physics: 'kinematic' | 'dynamic'):
1. Параметры ТС в src/scene.ts: масса, момент инерции по рысканию Iz, база, колея, положение центра масс
   (lf, lr, высота h), характеристики шин, распределение тормозных сил, ABS да/нет, привод.
   Каталог типовых значений по классам ТС с указанием источника; пользователь может ввести паспортные данные.
2. Модель движения: плоская модель с четырьмя колёсами (или двухколёсная «bicycle model» как первый шаг),
   продольный и поперечный перенос нагрузки, модель шины — Magic Formula (Pacejka) или Dugoff с
   эллипсом трения. Источники в комментариях.
3. Водитель-регулятор: следование траектории (pure pursuit / Stanley) и профилю скорости; если заданное
   невозможно по сцеплению — ТС уходит в занос/снос, и это видно, а не «едет по рельсам».
   Торможение: время реакции, запаздывание привода, нарастание замедления (параметры — задача 10).
4. Дорога: коэффициент сцепления по участкам (не одно покрытие на всю сцену), продольный и поперечный
   уклон, неровность — как зоны в редакторе.
5. Интегратор с фиксированным шагом (RK4 или полунеявный Эйлер; шаг ≤ 5 мс внутри DT = 25 мс),
   детерминированный. Энергетический тест на сохранение.
6. Тесты: торможение до остановки при μ и t сходится с v·t + v²/(2μg) в пределах 1 %; установившийся
   круговой поворот — недостаточная/избыточная поворачиваемость согласуется с градиентом поворачиваемости;
   критическая скорость на дуге радиуса R ≈ sqrt(μ·g·R).
7. Все существующие пресеты продолжают работать в обоих режимах; где динамика меняет исход, тест
   фиксирует оба режима.

Проверка: npm test, npm run build; производительность — пресет из 3 ТС на 10 с считается < 200 мс в Node.
```
