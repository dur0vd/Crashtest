# 08. Модель удара: импульс, вращение, энергия деформации

## Промпт

```
Прочитай AGENTS.md. Сейчас удар в Crashtest — поступательный обмен импульсом по нормали (src/sim.ts, Collision
с dvA/dvB), кузова не вращаются. Нужна модель, применяемая в реконструкции ДТП. Работай поверх
src/physics/ из задачи 07.

1. Импульсная модель удара (Kudlich–Slibar, как в широко используемых программах реконструкции):
   точка удара, плоскость контакта, коэффициент восстановления k (0…0.3 для ТС), коэффициент трения
   по плоскости контакта μc; полный и скользящий удар. Выход: Δv каждого ТС, изменение угловой скорости,
   PDOF (principal direction of force), EES.
2. Энергия деформации: метод CRASH3 (коэффициенты жёсткости A, B по классам ТС) — по профилю деформации
   C1…C6 вычислять энергию и EES; обратная задача — по EES оценить Δv. Таблица жёсткостей с источником.
3. Многократные удары (вторичные столкновения, удар о препятствие после первого), контакт с бордюром и
   отбойником.
4. Послеударное движение: качение/скольжение с заблокированными или свободными колёсами, вращение,
   остановка в конечном положении. Конечное положение должно совпадать с наблюдаемым — это основа
   обратной задачи (задача 12).
5. Отчёт столкновения: Δv, PDOF, EES, k, μc, угол рыскания после удара, путь отброса — в technical-разделе.
6. Оценка вреда (src/analysis — harmFor) переходит на Δv и PDOF с вероятностными кривыми (риск травмы
   MAIS3+ от Δv по опубликованным исследованиям — источник в комментарии). Вывод — вероятность, а не
   категория; категории тяжести вреда (лёгкий/средний/тяжкий) — только как ориентир с оговоркой, что их
   устанавливает судебно-медицинская экспертиза.
7. Тесты: сохранение импульса и момента импульса; k = 0 и k = 1 — предельные случаи; центральный удар
   совпадает с аналитическим; энергетический баланс (кинетическая до = после + деформация + трение).

Проверка: npm test, npm run build.
```
