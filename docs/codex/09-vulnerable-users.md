# 09. Пешеходы, велосипедисты, мотоциклисты

Ветка: `codex/09-vulnerable-users` ← от `codex/08-impact-model`

## Промпт

```
Работай в отдельной ветке codex/09-vulnerable-users. Создай её от codex/08-impact-model (если в origin её нет — остановись и сообщи, что сначала нужна та задача).
Не коммить в main и в чужие ветки. В конце: npm test и npm run build зелёные, коммит, git push -u origin codex/09-vulnerable-users.

Прочитай AGENTS.md. Сейчас пешеход в Crashtest — прямоугольник на траектории, а тяжесть вреда — порог по
скорости. Сделай модели, применимые в реконструкции наездов. Используй src/physics/ из задач 07–08.

1. Пешеход: темп движения по таблицам экспертной практики (шаг, быстрый шаг, бег; взрослый, ребёнок,
   пожилой — с источником), возможность резко остановиться/изменить направление.
2. Наезд на пешехода: фазы — контакт с бампером, накат на капот/лобовое стекло (зависит от формы передка:
   седан, внедорожник, грузовик/автобус), полёт, скольжение по дороге. Расстояние отброса по
   формулам, применяемым в реконструкции (например, Searle; Wood) — обе с источниками, выбор в
   параметрах. Обратная задача: по расстоянию отброса и месту наезда — диапазон скорости ТС.
3. Место наезда по следам: осыпь стекла, следы обуви/скольжения, положение тела — ввод через задачу 11.
4. Велосипед и мотоцикл: двухколёсная модель (опрокидывание, скольжение на боку с отдельным μ),
   отброс водителя отдельно от ТС.
5. Риски травм: вероятностные кривые от скорости удара для пешехода по возрастным группам
   (опубликованные исследования — с источником). В отчёте — вероятность, не диагноз.
6. Тесты: формулы отброса совпадают с опубликованными примерами; обратная задача возвращает исходную
   скорость на синтетических данных.

Проверка: npm test, npm run build.
```
