# 13. Анализ видео: скорость и положение по кадрам

## Промпт

```
Прочитай AGENTS.md. Самое частое объективное доказательство в спорах о ДТП — запись видеорегистратора или
камеры наблюдения. Добавь в Crashtest модуль покадрового анализа (всё в браузере, видео не уходит на сервер).

1. Загрузка видео, покадровая навигация, извлечение реальной частоты кадров и меток времени кадров
   (переменный FPS — частая ошибка; предупреждать, если метки неравномерны). Хэш исходного файла.
2. Калибровка неподвижной камеры: гомография «изображение → план дороги» по ≥ 4 точкам с известными
   координатами из сцены (разметка, углы перехода, опоры). Показать погрешность репроекции.
3. Разметка объекта на кадрах (ручная, точка контакта колеса с дорогой); расчёт положения на плане,
   скорости и ускорения со сглаживанием и доверительным интервалом с учётом погрешности клика и
   калибровки.
4. Камера в движущемся ТС (регистратор): скорость носителя по прохождению известных отметок (штрихи
   прерывистой разметки 1.5 известной длины, опоры), момент появления опасности в кадре.
5. Синхронизация видео с таймлайном симуляции и светофорным циклом; наложение смоделированных
   положений на кадр для визуальной проверки.
6. Результаты — наблюдения для обратной задачи (задача 12) с погрешностью.
7. Тесты: синтетическое «видео» (сгенерированные проекции известного движения) → модуль восстанавливает
   скорость в пределах заданной погрешности.

Проверка: npm test, npm run build.
```
