# 16. Режим аварийного комиссара (работа на месте ДТП)

Ветка: `codex/16-commissioner-mode` ← от `codex/11-scene-evidence` + влить `codex/02-law-versions`, `codex/14-expert-report`, `codex/15-audit-trail`

## Промпт

```
Работай в отдельной ветке codex/16-commissioner-mode. Создай её от codex/11-scene-evidence (если в origin её нет — остановись и сообщи, что сначала нужна та задача).
Перед началом влей в неё (git merge, без rebase): codex/02-law-versions, codex/14-expert-report, codex/15-audit-trail; конфликты разреши, сохранив поведение обеих веток.
Не коммить в main и в чужие ветки. В конце: npm test и npm run build зелёные, коммит, git push -u origin codex/16-commissioner-mode.

Прочитай AGENTS.md. Аварийный комиссар работает с телефона на месте ДТП, часто без связи, за 20–40 минут.
Сделай в Crashtest отдельный режим (переключатель в меню), оптимизированный под это. Мобильная сборка —
Capacitor (android/, ios/).

1. Мастер по шагам: дата/время/адрес (геолокация) → тип места (шаблоны: перекрёсток, Т-образный,
   кольцо, парковка, прямая) → участники (тип, госномер, полис ОСАГО — поля) → положение ТС
   (перетаскиванием на шаблоне) → следы и осыпь → повреждения (схема кузова, тап по зоне) → фото →
   пояснения участников (текст/диктовка) → предварительный разбор.
2. Фото с камеры: геометка, время, хэш, привязка к объекту схемы; обязательный набор ракурсов
   (общий план, номера, повреждения, положение относительно разметки) как чек-лист.
3. Измерения: ввод с рулетки/дальномера; опционально AR-измерение (ARCore/ARKit через плагин Capacitor) —
   с явной пометкой точности.
4. Европротокол (ст. 11.1 закона об ОСАГО): проверка условий оформления без полиции (число ТС,
   отсутствие вреда здоровью, лимиты, разногласия) по редакции на дату (задача 02); подсказка, какие
   поля бланка заполнить. Не имитировать официальные сервисы и бланки — только подсказки.
5. Предварительная оценка для ОСАГО: нарушения ПДД в причинной связи по каждому участнику; если
   определить невозможно — указать, что по закону об ОСАГО (п. 22 ст. 12) страховщик выплачивает в равных
   долях до установления вины судом (TODO(legal-check) сверить пункт). Степень вины в процентах
   не выдавать.
6. Офлайн: всё работает без сети, синхронизация/экспорт .crashtest (задача 15) позже.
7. Итог — «Справка аварийного комиссара» (шаблон из задачи 14).
8. UX: крупные элементы, работа одной рукой, тёмная тема на солнце — светлая высококонтрастная.

Проверка: npm test, npm run build; ручная проверка мастера на ширине 360 px (playwright-скриншоты в PR).
```
