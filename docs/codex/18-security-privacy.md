# 18. Персональные данные, хранение, безопасность

## Промпт

```
Прочитай AGENTS.md. Как только в Crashtest появляются госномера, ФИО, полисы, фото и видео с места ДТП
(задачи 11, 13, 16), это персональные данные (152-ФЗ). Сделай так, чтобы приложение было безопасным
по умолчанию.

1. Хранение только локально (IndexedDB / файловая система устройства через Capacitor); никаких отправок
   на внешние серверы без явного действия пользователя. Аудит кода на fetch/XHR к сторонним адресам —
   тест, который падает, если в сборке появился неразрешённый внешний URL.
2. «Поделиться по ссылке» (сейчас сцена кодируется в URL): в режимах комиссара/эксперта запретить для
   проектов с персональными данными или вырезать их с предупреждением.
3. Шифрование проекта паролем при экспорте (.crashtest — AES-GCM через WebCrypto, PBKDF2/Argon2).
4. Обезличивание: кнопка «экспорт без ПДн» — заменить ФИО/номера на «Участник 1», размыть номера и лица
   на фото (ручная разметка областей; автоматическое распознавание — опционально и локально).
5. Удаление: полное удаление проекта и вложений с устройства.
6. Документ docs/PRIVACY.md: какие данные, где хранятся, кто оператор (пользователь), шаблон согласия
   участников ДТП на обработку, рекомендации комиссару. Юридические формулировки — TODO(legal-check).
7. CSP в index.html, зависимость-аудит (npm audit) в CI.

Проверка: npm test, npm run build.
```
