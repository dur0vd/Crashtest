# 19. Учебный режим для автошкол (по желанию)

## Промпт

```
Прочитай AGENTS.md. Помимо экспертного применения Crashtest используют в автошколах. Сделай учебный режим.

1. «Угадай»: перед показом разбора задать вопросы — «Кто должен уступить?», «Какой пункт ПДД нарушен?»,
   «Мог ли водитель остановиться?» — варианты ответов генерируются из отчёта (правильный + правдоподобные
   неверные из того же раздела ПДД). После ответа — разбор с выделением ошибки.
2. Каталог сцен по темам экзаменационных билетов категорий AB (перекрёстки, обгон, переходы, остановка,
   переезды, спецтранспорт…), фильтр по теме и сложности.
3. Режим преподавателя: «проектор» — крупные знаки и подписи, пауза на ключевом моменте с вопросом
   классу, пошаговое воспроизведение; набор сцен в «урок» и ссылка на урок для учеников.
4. Вид от водителя (простой 3D или псевдо-3D) из точки водителя в момент возникновения опасности —
   показывает обзорность (задача 10).
5. Знаки на холсте при мелком масштабе не исчезают: минимальный экранный размер значка.
6. Шаблоны «Новая ситуация»: Т-образный перекрёсток, крестообразный, кольцо, двор, загородная дорога.

Проверка: npm test, npm run build; скриншоты учебного режима на 1400 px и 390 px в PR.
```
