## Подэтап 15/18: проектная основа

Реализованы DOM-независимые canonical/SHA256/ZIP, неизменённые оригиналы,
manifest хэшей payload, лимиты и пути импорта, миграция старого Scene,
версии, журнал было/стало/кто/время, undo/redo/restore, IndexedDB CRUD,
общий verifier с инъекцией портов и diff, локальный CLI, PBKDF2/AES-GCM,
консервативный обезличенный производный проект (без оригиналов/истории/расчётов).

Числа: shortest round-trip ECMAScript JSON, без потери значащих разрядов;
-0 канонизируется в 0, NaN/Infinity/undefined отвергаются. Это сознательно
не фиксированное количество десятичных знаков для разноразмерных измерений.
SHA-256 не является электронной подписью/доказательством автора.
Версии неподключённого engine/corpus честно unavailable/unrecorded.

CLI: `npm exec -- crashtest-verify project.crashtest`,
`npx --no-install crashtest-verify --help` после npm install.
`--integrity-only` явно отделён от пересчёта. Без PhysicsPort exit 3.
Пароль: `--password-env NAME` (значение не печатается).
Интегратор передаёт реальные порты в `main(args, ports)` / `verifyProject`.

Проверки и последующие подэтапы дополняются в этом же отчёте.

Проверка подэтапа: `npm test` 1126/1126 (36 файлов), `npm run build` успешно;
`npm exec -- crashtest-verify --help` успешно. Все исходные 1115 тестов сохранены.
Проверка ZIP не распространяется на legacy JSON (integrity: not-checked).

## Подэтапы 11/13/14: реальные материалы и документы

Evidence: каталог следов/осыпи/места удара/поз/C1–C6/сигналов, источники,
погрешности, проверка конфликтов без перезаписи наблюдений, survey-привязка
двумя ориентирами; масштабный физический SVG и векторный PDF с размерами.
Оригинальные фото читаются без перекодирования, SHA-256 и EXIF через exifr.
Ручная маска создаёт локальный PNG-производный, оригинал не модифицируется.

`LocalVideo`: демультиплексирование локальных MP4/MOV/WebM/MKV/OGG/TS через
Mediabunny (MPL-2.0), без HLS/сетевых источников; индекс PTS и длительностей,
VFR-предупреждение, декодирование точного кадра через WebCodecs с проверкой PTS.
`videoCalculation` делегирует математические методы PhysicsPort; без порта
unsupported. Есть измеренная синхронизация PTS↔Timeline, не FPS/seek.
Fixture `tests/fixtures/graphics/vfr.webm` создан локально ffmpeg testsrc2,
пять реальных PTS 0/.04/.12/.16/.28 подтверждены ffprobe. Синтетический fixture,
не натурная валидация. Лимиты 128 MiB на вложение, 200000 кадров на индекс.
Кодек без поддержки браузером честно не даёт размечать декодированный кадр.

PDF/DOCX: три шаблона, материалы/хэши/параметры/погрешности/trace/формула/
подстановка/единицы/источники, ответы только по существующим calculation-ID,
technical/rules/legal раздельно. Legal выключен по умолчанию для всех шаблонов;
текст норм приходит только из переданного Report. DejaVu Sans TTF локально,
оригинальная лицензия в public/fonts/DejaVu-LICENSE.txt. PDF открывается
pdf-lib и pdftotext; кириллица и полный хэш извлекаются, DOCX проверен как ZIP/XML.

`npm test`: 1136/1136, 38 файлов, 3 snapshots для существующих пресетов.
`npm run build`: успешно. Существующие пресеты содержат optional undefined;
на границе Scene→envelope они явно опускаются, канонизация самого JSON строгая.

## Подэтапы 16/18: рабочая область, мобильный осмотр, защита

Публичный экспорт: `src/workbench/mount.ts` →
`mountWorkbench(element, {project, ports, onProjectChange})` → `{destroy()}`.
Optional host-адаптер: file/onFileChange/versions; обязательный контракт 1 прежний.
Подробные пути, форматы адаптеров и инструкция — `docs/GRAPHICS-WORKBENCH.md`.
В существующем приложении: Меню → Материалы, проекты и мобильный комиссар.
Ни один factory отсутствующего соседнего чата не импортирован.

Реально подключено к UI:

- describe-формы (числа/единицы/границы/enum/геометрия/три состояния факта),
  t1–t3/j с диапазонами и источниками, графический ввод зон + редактирование
  измеренных уклонов/профиля неровностей в JSON;
- evidence create/edit/delete, координаты на плане, источники/погрешности/
  комментарии, колесо/ABS/ширина, уверенность/кем установлено, конечные позы,
  C1–C6/высота сечения, связь с оригинальными вложениями, два ориентира,
  калибровка прозрачной растровой подложки, SVG/PDF;
- оригиналы и EXIF/SHA-256, локальное маскирование → отдельный PNG;
  реальный индекс/декодирование VFR, wheel-ground/4+ калибровочных точек,
  редактирование/удаление меток, измеренное соответствие PTS/Timeline/сигнала,
  отображение предоставленных портом пиксельных overlay;
- реконструкция через calculate/simulate, progress/cancel с отсечением позднего
  результата, невязка по каждому evidence (включая «не предоставлена»),
  графики line/histogram/tornado из CalculationRecord, полный численный trace;
- Timeline на существующем Renderer; исправлено использование его реального dt
  вместо DT в трёх местах. Никакой новый скрытый симулятор не добавлен.
  renderData wheels/vectors/visibility рисуется по документированному адаптеру;
- PDF/DOCX и обезличенный PDF, введённые реквизиты/вопросы/calculation-ID,
  реальные графики в обоих форматах, сохранённые результаты со stale-hash guard;
- ZIP/import/encryption/undo/redo/откат/журнал/проверка воспроизводимости/
  удаление доступны пользователю; old Scene сохраняется совместимым;
- девять шагов мобильного мастера, пять шаблонов места, номера/ОСАГО/контакты,
  позиции на плане, измерения рулеткой и точность, tap-повреждения, camera input,
  чек-лист фото, текст и явная локальная аудиозапись, геопозиция с точностью;
- IndexedDB вместо новых записей ПДн в localStorage; последовательная очередь
  записи/удаления и snapshot при автосохранении; старое сохранение мигрируется;
  URL-share отключён, CSP, allowlist статических ресурсов, офлайн precache;
  Android backup выключен, permission descriptions добавлены в Android/iOS.

Мобильная оболочка и интерфейс не отправляют материалы на внешние сервисы.
Диктовка: честный текстовый fallback и локальная аудиозапись; облачный
SpeechRecognition не запускается. Redacted ZIP намеренно исключает **все** фото
(также маскированные производные), EXIF, свободный текст, номера/полисы/контакты,
журнал/старые состояния, сохранённые результаты и исходные extensions.
Это отдельная производная схема, не оригинал. Подробности — `docs/PRIVACY.md`.

## Что передать интегратору; ограничения

1. Подключить реальные factories к `openWorkbench` в src/main.ts вместо `{}`
   и передать их же в `src/cli/verify.ts main(args, ports, versions)`.
   verifyProject принимает actual versions отдельно; если их нет, статус
   сопоставления unavailable, равенство не предполагается. Ветка сама не
   выдаёт отсутствие движка за готовую динамику/удар/правовую квалификацию.
2. Согласовать реальные JSON-схемы диапазонов braking, video parameters,
   diagnostic figures/residuals и renderData с документированным адаптером.
   Не менялись contracts.ts и научные/правовые схемы Scene. Незнакомые данные
   портов доступны в trace и сохраняются; автоматическая визуализация иной
   схемы требует адаптера интегратора, а не выдуманной UI математики.
3. Старая кнопка ▶ остаётся прежним реально работающим simulate/analyze.
   Интегратор объединяет её pipeline с реальной динамикой согласно своей задаче.
   Здесь отсутствующий PhysicsPort не заменяется ни этим кодом, ни mock.
4. Научные противоречия/полные residuals/видимость/проекции видео/европротокол
   приходят из реальных портов. UI самостоятельно проверяет структуру/известность
   и расхождение предоставленных точек с погрешностью, а не заново считает
   физическую допустимость. Новых штрафов, медицинских кривых или норм нет.
5. Нативные релизы и проверки на устройствах остаются неподтверждёнными из-за
   SDK. Поддержка видеокодека зависит от WebCodecs браузера; оригинал и PTS
   при этом сохраняются, ложного расчёта скорости нет.
6. Экспорты подписываются хэшами payload, не электронной подписью. Шифрование —
   для файлов экспорта; IndexedDB в профиле браузера не зашифрован. Полное
   удаление касается локального проекта/вложений приложения, не чужих копий.
7. TODO(legal-check) только по процессуальной структуре/согласию/основаниям
   обработки; перечислены в docs/PRIVACY.md и генераторе отчёта. Без них
   выполнены все независимые редакторы, реальные форматы и проверки.
8. Необязательные OSM, AR, автоматическое распознавание лиц/номеров и отдельный
   учебный режим 19 не реализованы; пять шаблонов места доступны в мастере.
