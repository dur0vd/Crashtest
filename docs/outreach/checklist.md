## Выдача кодов

```bash
# закрытый ключ лежит в ~/.crashtest/license-private.pem (или путь в CRASHTEST_KEY)
node tools/issue-code.mjs school "Автошкола Старт"      # 30 дней
node tools/issue-code.mjs personal "Иван Петров"
node tools/issue-code.mjs school "Автошкола Старт" 60   # пилот на 60 дней
```

Код отправьте покупателю письмом. Он вводит его в меню → «Подписка» → «Активировать». Учёт выданных кодов ведётся в `~/.crashtest/issued.csv`.
