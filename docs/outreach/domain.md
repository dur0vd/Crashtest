# Домен для Crashtest: выбор, покупка, подключение

Домен покупаете вы (нужна оплата и ваши данные), всё остальное в репозитории я подготовлю за несколько минут после того, как вы назовёте домен.

## Какое имя взять

Требования: короткое, читается с листовки и диктуется по телефону, без дефисов и цифр, зона `.ru` (школам привычнее и дешевле).

Варианты по приоритету (доступность проверьте на сайте регистратора, я её проверить не могу):
1. `crashtest.ru`
2. `crashtest-pdd.ru`
3. `razbor-dtp.ru`
4. `dtp-lab.ru`
5. `crashtest.app` или `crashtest.site` (если `.ru` занят)

## Где купить

Любой аккредитованный регистратор: reg.ru, nic.ru, timeweb.com, beget.com. Цена `.ru` обычно 200–400 ₽ в год. При регистрации `.ru` потребуются паспортные данные владельца (физлицо или ИП). Включите автопродление, иначе домен может «умереть» вместе с напечатанными QR-кодами.

## Как подключить к GitHub Pages

1. В DNS-настройках домена у регистратора добавьте четыре A-записи для `@` (корня) со значениями:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
2. Добавьте запись `CNAME` для `www` со значением `dur0vd.github.io`.
3. В репозитории откройте Settings → Pages → Custom domain, впишите домен и сохраните. Когда GitHub проверит DNS (от нескольких минут до часов), включите галочку Enforce HTTPS.
4. Сообщите мне домен. Я добавлю файл `public/CNAME`, обновлю адрес в `og:image` (`index.html`, `public/about.html`), перегенерирую QR-код и подставлю адрес в листовку (`TODO-URL` в `docs/outreach/flyer.html`).

Пока домена нет, всё работает на `https://dur0vd.github.io/Crashtest/`. QR-код на текущий адрес уже лежит в `public/promo/qr-flyer.svg`.

## Почта на домене (по желанию)

Для писем школам выглядит солиднее, чем `mail.ru`: например `hello@ваш-домен.ru`. Многие регистраторы дают бесплатную пересылку на ваш ящик. Если заведёте, скажите, и я заменю контакт на сайте и в материалах.
