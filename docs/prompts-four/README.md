# Четыре чата

Первые три промпта запускаются одновременно в трёх отдельных чатах.
У каждого своя ветка и рабочая копия. Только четвёртый ждёт их результаты.
Общая проверенная база: `codex/full-simulator-base-v2`.

| Чат | Отдельный промпт | Ветка | Модель |
| --- | --- | --- | --- |
| 1 | [Физика](01-physics.txt) | `codex/parallel-physics` | Claude Opus 5.5 |
| 2 | [Графика и интерфейс](02-graphics.txt) | `codex/parallel-graphics` | Claude Sonnet 5.5 |
| 3 | [Правила](03-rules.txt) | `codex/parallel-rules` | Claude Opus 5.5 |
| 4 | [Проверка и объединение](04-check-and-merge.txt) | `codex/parallel-integration` | GPT-6.1 Sol high |

В файлах уже есть общие правила, команды, границы и критерии. Можно передать
содержимое одного TXT новому чату с доступом к репозиторию, не копируя соседние.
Модели — рекомендация; альтернативы указаны внутри. Sol выбирать в Codex/Work,
Claude — в Claude Code с терминалом и проектом.

Проверенная база: 1115 тестов/35 файлов и production build. Готовые парковка,
СИМ и пассажиры включены с их ограничениями; ядро 07.1 включено, но динамика сцены 07.2 и удар ещё не готовы.
[Подробная проверка](../STATUS-AUDIT-2026-10-22.md),
[границы и типы](../PARALLEL-CONTRACT.md), [реестр четырёх веток](plan.json).
