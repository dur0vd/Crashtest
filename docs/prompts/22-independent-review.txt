Только чтение и независимые проверки. Не менять исходники, не коммитить,
не пушить и не переписывать историю. Сначала проверить git status/log,
сохранять незавершённую работу. Прочитать AGENTS.md и docs/codex/README.md,
если они появились, затем docs/FULL-SIMULATOR.md и полный исходный запрос
в docs/FULL-SIMULATOR-REQUEST.md. Для запуска тестов использовать отдельные
временные артефакты; не стирать материалы проекта.

Проверь последний завершённый этап в codex/04-full-simulator.
Сначала прочитай его задачу из docs/REMAINING-WORK.md, исходный запрос,
git diff коммита и реальные тесты. Не считай зелёный тест доказательством,
если ожидаемое значение повторяет реализацию.
Ищи ложные правовые выводы, потерю неизвестности/источников, нарушения
единиц/балансов, скрытый fallback, недетерминизм и потерю исходных материалов.
Используй независимый наблюдаемый/аналитический пример.
Сообщи только существенные находки: файл/строка, воспроизведение,
последствие и конкретное исправление. Код пока не меняй.
Если находок нет, перечисли проверенные сценарии и оставшиеся пределы.
